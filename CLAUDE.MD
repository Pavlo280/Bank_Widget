# CLAUDE.md — Bank_Widget

## О проекте
Учебный проект (курс по Python). Виджет банковских операций: маскирование
номеров карт/счетов и форматирование дат. Автор учится — поэтому ОБЪЯСНЯЙ
решения по ходу, а не просто выдавай готовый код.

## Структура
- `src/masks/masks.py` — `get_mask_card_number`, `get_mask_account` (низкоуровневое маскирование)
- `src/widget.py` — `mask_account_card`, `get_date` (логика виджета поверх masks)
- `main.py` — демонстрационный запуск
- `tests/` — pytest-тесты (пока пусто)

## Инструменты
- Зависимости: **Poetry**
- Формат/линт: black (119), isort (119, force_single_line), flake8, ruff, mypy
- mypy строгий: `disallow_untyped_defs = true` → у всех функций обязательны аннотации типов
- Тесты: pytest (+ pytest-cov для покрытия)

> Известный рассинхрон: black/isort = 119, а ruff = 88. При случае выровнять.

## Команды
- Установка:   `poetry install`
- Запуск:      `poetry run python main.py`
- Тесты:       `poetry run pytest`
- Покрытие:    `poetry run pytest --cov=src --cov-report=term-missing`
- Формат:      `poetry run black . && poetry run isort .`
- Проверка:    `poetry run mypy src && poetry run flake8`

## Соглашения
- Все функции — с аннотациями типов и docstring на русском.
- Изменения минимальные и точечные: не переписывай то, о чём не просили.
- GitFlow: фичи в отдельных ветках, ветвление от develop.

## Как мы работаем (важно)
- Объясняй ЧТО и ЗАЧЕМ ты делаешь, простыми словами — автор должен понимать суть.
- Сначала подход/идея, потом код.
- Если задание неоднозначно — задай один уточняющий вопрос, а не выдумывай требования.
